# mi primer repositorio
En este mini proyecto he los siguientes proyectos:

- `git clone`
- `git log`, con modificadores --oneline y --all
- `git checkout`
- `git add .`
- `git commit -m "mensaje"`
- `git diff`
- `git remote`, incluyendo get-url y set-url
- `git merge`, para arreglar una cosita
- `git push`
